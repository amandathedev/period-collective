# How to publish a blog post on theperiodcollective.org

Hi Audrey! Below is everything you need to write and publish posts to our new blog at [theperiodcollective.org/blog](https://theperiodcollective.org/blog). It's all done through Contentful — no code or developer needed. Once a post is published it shows up on the site within a minute or two.

## Step 1 — Log in

Go to [app.contentful.com](https://app.contentful.com) and log in with the email you've been invited under. You'll land in the **Period Collective** space.

## Step 2 — Create a new post

1. Click **Content** in the top nav.
2. Click the green **+ Add entry** button (top right).
3. Choose **Blog Post** as the content type.
4. A blank entry opens — this is where you write the post.

## Step 3 — Fill in the fields

| Field | What goes here |
|---|---|
| **Title** | The post headline. |
| **Slug** | The URL path. Lowercase letters, numbers, and hyphens only — no spaces, no uppercase, no punctuation. Example: `back-to-school-drive-2026`. The post will live at `theperiodcollective.org/blog/{slug}`. Each slug must be unique. |
| **Publish date** | When the post should be dated. Newest posts appear first on the blog index. |
| **Hero image** | Optional banner image. Shown at the top of the post and on the blog list card. Click **+ Create new asset and link** to upload, or pick one already in the media library. |
| **Excerpt** | Optional. A one- or two-sentence preview that shows on the blog list page. If you skip it, only the title shows on the card. |
| **Body** | The actual post — see Step 4 below. |
| **Tags** | Optional list of short lowercase tags (e.g. `event`, `partnership`, `news`). They become filter chips on the blog index, so people can browse by topic. |

## Step 4 — Write the body

The Body field uses Contentful's **Rich Text** editor — like Google Docs but simpler. You can:

- Use the toolbar for **bold**, *italics*, headings, lists, blockquotes, and links.
- Press Enter for paragraph breaks.
- Insert images inside the post by clicking the **+** button on a new line, then **Embed asset** → either upload a new image or pick an existing one. Tip: when you upload an image, fill in the asset's **Description** field — that becomes the alt text (important for accessibility), and the **Title** field becomes the caption shown under the image.
- Add links by selecting text and clicking the link icon. Links to other websites will open in a new tab automatically.

## Step 5 — Publish

When you're ready, click the green **Publish** button in the top right of the entry.

If you see a yellow **Save** button instead, click Save first, then Publish. Saving alone doesn't make it live — only **Publish** does that.

Within a minute or two the post appears on the website.

## Editing or unpublishing later

- **To edit a published post:** open the entry, change what you want, click **Publish** again.
- **To hide a post without deleting:** open the entry → click the status menu in the top right → **Unpublish**. This pulls it from the site but keeps the entry in Contentful so you can re-publish later.
- **To permanently delete a post:** unpublish first, then delete from the same menu.

## Important: don't change the slug after publishing

Once a post is live and you've shared the link anywhere — social posts, newsletters, emails — the slug becomes part of the URL. Changing the slug breaks every existing link to that post.

If you need to rename a post, change the **Title** (that's safe) but leave the **Slug** alone. If you really must change the URL, unpublish the old post and create a new entry with the new slug.

## A few small things

- **The Blog tab in the site navigation only appears once at least one blog post is published.** So when you publish your very first post, the **Blog** link will start showing in the menu. There may already be a test post called "Hello from Claude Code" — feel free to unpublish or delete that whenever.
- **Drafts are private.** A saved-but-unpublished entry is only visible to people logged into Contentful. You can come back to a draft anytime.
- **Images get reused.** Once you upload an image, it lives in the **Media** tab and you can reuse it across posts.
